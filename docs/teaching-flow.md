# 完整教学流程设计（设计对齐 v0.1）

> 前情：`study-loop-design.md` 是「学习管理闭环」（数据/管理视角），
> 本文档是「教学流程」（教育学视角）——把因材施教落到每一步怎么教。
> 两者互为表里：管理闭环管「学没学完」，教学流程管「怎么教会」。

## 1. 四层流程结构

```
宏观（学科/目标级）   摸底画像 → 定目标 → 定方案 → 阶段循环 → 完成
中观（单元/主题级）   导学 → 讲授 → 练习 → 测验 → 错题 → 复习
微观（单次会话级）    回顾 → 微目标 → 学习 → 输出 → 记录 → 衔接
贯穿（因材施教决策）  风格/节奏/难度/动机/干预 动态决策
```

## 2. 宏观流程：从开始到学完（8 步）

| # | 环节 | 具体动作 | 产出 | 驱动 |
|---|------|---------|------|------|
| 1 | 摸底与画像 | 前测/访谈/行为观察：起点、薄弱点、学习风格、可用时间 | 画像 + 基线 | LLM+规则 |
| 2 | 目标设定 | SMART 目标 + 验收标准，用户确认 | 目标卡 | LLM+用户 |
| 3 | 方案制定 | 内容序列 + 节奏 + 教法 + 复习计划 + 评估点 | 个性化方案 | LLM |
| 4 | 阶段教学 | 按单元循环执行（见中观） | 学习记录 | 三方 |
| 5 | 阶段验收 | 测验 + 掌握度 + 任务完成证据 | 验收报告 | 规则+LLM |
| 6 | 数据分析 | 进度/掌握度/复习/行为趋势 | 分析报告 | 规则+LLM |
| 7 | 动态调整 | 改内容/节奏/教法/复习（用户确认） | 新方案 | 用户确认 |
| 8 | 完成判定 | 验收全过 + 复习稳定 → 总结沉淀 | 完成报告 | 规则+用户 |

## 3. 中观流程：一个单元怎么教（8 步）

```
① 导学：激活旧知（连到已学内容），说明本单元目标
② 讲授：按画像选呈现方式（讲解/案例/图表/实操/类比）
③ 理解确认：提问 / 让用户复述（主动回忆第一击）
④ 练习：先脚手架引导 → 后独立完成；穿插交错练习
⑤ 反馈纠正：诊断错误类型（概念不清/粗心/没见过）→ 针对性讲解
⑥ 测验：小测自测，出掌握度分
⑦ 错题沉淀：错题进错题本，关联知识点
⑧ 复习调度：本单元进入间隔队列（1/3/7/14/30 天）
```

## 4. 微观流程：一次学习会话（6 步）

```
① 回顾：快速复习上次内容（连接上下文）
② 微目标：设定本次 15-30 分钟目标
③ 学习：讲授/练习交替，番茄钟管理专注（25+5）
④ 输出：主动回忆/费曼讲解/做题（生成效应）
⑤ 记录：学习时长、掌握度、卡点 → 写入学习记录
⑥ 衔接：总结本次 + 预告下次内容与任务
```

## 5. 贯穿：因材施教决策矩阵（每步都在用）

| 维度 | 判断依据 | 决策规则 |
|------|---------|---------|
| 呈现方式 | 画像风格 | 视觉→图表/思维导图；听觉→讲解/播客；读写→笔记/文章；动觉→实操/项目 |
| 节奏 | 行为数据 | 完成率高→加量；频繁中断→减量分块 |
| 难度 | 测验正确率 | 正确率≥80%→升难度；<60%→降难度回补；ZPD 动态调 |
| 动机 | 记录/汇报 | 里程碑庆祝；目标回顾唤醒动机；给自主选择权 |
| 干预 | 异常检测 | 停滞→询问；卡点→换教法；疲惫→提醒休息 |
| 复习 | 遗忘曲线 | 按掌握度定间隔：生疏→短间隔，熟练→拉长 |

## 6. 实时跟进（贯穿全程的"眼睛"）

- 进度看板：计划/单元/任务/复习实时状态
- 提醒：学习提醒、复习提醒、逾期提醒
- 异常检测：连续 N 天无记录、进度停滞、掌握度下滑 → 主动问
- 卡点救援：用户说「不会」→ 诊断 → 换教法/降难度/给类比
- 复盘：每阶段/每周数据回顾 + 下阶段建议

## 7. 与现有实现的对照

| 流程环节 | 现状 | 缺口 |
|---------|------|------|
| 摸底画像 | 无 | 画像数据层（风格/时段/基线） |
| 目标/方案 | plan_create 部分覆盖 | 验收标准、复习策略、教法字段 |
| 讲授/答疑 | 对话 LLM 天然具备 | 无需开发（靠提示词） |
| 理解确认/输出 | 无结构化支持 | 复习/自测工具 |
| 测验/掌握度 | 无 | 评估模块（测验/评分） |
| 错题本 | 无 | 错题模块（归因/关联知识点） |
| 复习调度 | 无 | 间隔重复引擎 |
| 数据分析 | 仅 pace | 趋势/达成/稳定性分析 |
| 干预/提醒 | 提醒有，干预无 | 停滞检测、卡点救援 |
| 完成判定 | 手动 | 证据驱动判定 |

结论：教学流程的「讲授/答疑」环节 LLM 天生具备（对话能力），
真正的工程增量集中在：画像、评估、错题、复习调度、干预、分析六个模块。
